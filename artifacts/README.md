# Paper artifacts

This directory contains the frozen artifacts used to compute the values in
manuscript version 4. Long experiment tags from the working directory were
replaced with stable public names. See `../docs/ARTIFACT_MANIFEST.md` for the
table- and figure-level mapping.

- `metrics/`: Baseline, RAG, and final WEA-RAG aggregate metrics.
- `predictions/`: Standalone RAG predictions and final WEA-RAG dual traces.
- `retrieval/`: Exact top-8 retrieval traces used by the reported runs.
- `web_cache/`: Shared SerpAPI search cache used by the cache-available runs.
- `analysis/`: Selector tuning and offline ablation outputs.
- `figures/published/`: Figure files used while preparing the manuscript.
- `figures/reproduced/`: Figures regenerated by the public analysis script.

`SHA256SUMS` covers the frozen numerical inputs, selector configuration, and
published figures. Files under `analysis/` with `reproduced` in their names and
files under `figures/reproduced/` are deterministic derived outputs and can be
regenerated with `scripts/reproduce_paper_analysis.sh`.
