version 4. Each HotpotQA retrieval setting contains 7,405 questions.

## Auxiliary analyses and figures

- `artifacts/analysis/ablation_reproduced.md` contains gate ablation, selector
  ablation, retrieval-difficulty buckets, and bootstrap statistics used by the
  manuscript analyses.
- `artifacts/analysis/selector_tuning.json` records the final post-hoc selector
  settings and source run tags.
- `artifacts/figures/published/` contains the manuscript preparation figures.
- `artifacts/figures/reproduced/` contains figures regenerated by the released
  analysis code.
- `docs/ARTIFACT_MANIFEST.md` maps every table and result figure in manuscript
  version 4 to its frozen source files and regenerated outputs.

Run the following commands to validate the frozen artifacts and regenerate the
tables and figures:

```bash
sha256sum --check artifacts/SHA256SUMS
bash scripts/prepare_data.sh
bash scripts/reproduce_paper_analysis.sh
```

The final WEA-RAG values are full-dev post-hoc results obtained from saved dual
prediction traces with a shared web cache. Standalone RAG and WEA-RAG were
separate inference runs with different generation limits, so their difference
is a pipeline-level comparison rather than an isolated causal estimate of web
evidence alone.
